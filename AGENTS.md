# AGENTS.md — Правила сотрудничества с AI

## Общие принципы

- **Язык:** `README.md` — только на английском, имена файлов/переменных — на английском.
- **Минимализм:** не добавлять комментарии к очевидному коду. Объяснять только _почему_, а не _что_.
- **Без чат-бота:** никаких вступлений, итогов, фраз вроде «вот ваш код» или «готово». Только результат.
- **Без revert:** не откатывать изменения, если пользователь не просил явно.

## Стек и стандарты

- **Язык:** C23 (`CMAKE_C_STANDARD 23`), `defer { }` из `base.h` для автоматического освобождения ресурсов
- **CMake:** 3.10+, CMake presets (`CMakePresets.json`), Ninja-генератор, сборки в `build/debug/` и `build/release/`
- **Третий код:** `thirdparty/base.h` — arena, string, defer. Реализация через `src/base.c`. `thirdparty/stc/coption.h` — парсинг аргументов CLI.

## Стиль кода

- **Именование:** `snake_case`, префиксы для уникальности:
  - функции: `string_trim`, `arena_reset`, `list_append`
  - типы: `string`, `string_builder`, `arena_temp`
  - макросы: `UPPER_CASE`, `ARRAY_SIZE`, `S()`
- **Типы base.h:** использовать `u8`–`u64`, `i8`–`i64`, `usize`, `isize`, `string`, `arena`.
- **Строки:** никогда не использовать `char*` напрямую. Всегда `string` + `STR_FMT`/`STR_ARG` для вывода.
- **Память:** только arena-аллокация. Никаких `malloc`/`free` в пользовательском коде.

## CMake

- `target_include_directories` → `thirdparty`
- `src/_i_base.c` всегда в `add_executable`
- Не добавлять `find_package` без крайней необходимости

## Git

- Коммитить только по запросу пользователя
- Сообщение: краткое, про _почему_, не про _что_
- `build/` в `.gitignore`

## Поведение AI

1. **Планирование:** для сложных задач — краткий план перед реализацией.
2. **Валидация:** всегда использовать `cmake --build build/debug && ./build/debug/luna` для сборки и запуска. Не делать чистую сборку, не запускать команды по отдельности.
3. **Контекст:** читать существующий код перед правкой. Соблюдать конвенции проекта.
4. **Без догадок:** если неясно — задать вопрос, а не решать за пользователя.
5. **Файлы-артефакты:** тесты, конфиги, новые `.c`/`.h` — постоянные артефакты, не удалять.
